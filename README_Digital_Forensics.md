# Digital Forensics — Evidence Acquisition & Analysis

**Author:** Pedro Gonçalves  
**Focus:** Digital Forensics · Evidence Acquisition · Disk Imaging · Forensic Artefact Analysis

## Overview

A hands-on digital forensics laboratory documenting the preparation of a Windows analysis environment, forensic disk imaging with **Exterro FTK Imager**, and evidence examination using **Autopsy**. The technical report includes laboratory screenshots and explanations of the investigative workflow.

## Technologies

- **Exterro FTK Imager** — evidence source selection, disk imaging and acquisition metadata.
- **Autopsy / The Sleuth Kit** — forensic case management, ingest, artefact examination and reporting.
- **Windows** — virtual disk creation, partitioning and forensic workstation preparation.
- **NIST CFReDS** — sample forensic disk images for training and analysis.

## Laboratory workflow

1. Prepare the forensic workstation and dedicated virtual storage.
2. Select a disk evidence source and review RAW/dd and E01 image formats.
3. Create an Autopsy case and import a forensic image.
4. Configure ingest modules and examine file types, recovered files and deleted data.
5. Review metadata, browsing artefacts, recent documents, USB history and timeline information.
6. Tag relevant artefacts and generate an HTML investigation report.

## Ethical and forensic considerations

All work was performed as an educational laboratory exercise using test evidence. The documentation illustrates investigative techniques; it does not claim legal chain-of-custody certification or a real-world incident investigation. Actual investigations require verified integrity hashes, controlled access, appropriate authorization and rigorous evidence handling.
